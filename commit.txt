adding commit keep track of our progress and changes as we work.
git considers each commit change point or save point,it is a point where you go back to it if you found bug or want to make change

#commands:

git commit -m "message"

sometimes when you make small changes, using the staging enivronment seems like waste of time, it is possible to commit changes directly, skipping staging environment:

that means create a file & run following command

git commit -a -m " commiting the file with skipping staging env"

# to use this this should already staged and when you modify the file we can run the "git commit -am "message" "with out staging "git add "
